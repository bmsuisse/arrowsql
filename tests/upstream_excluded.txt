# INAPPLICABLE = ODBC/C++/upstream-CI internals with no meaning for a native-TDS core.

test_000_dependencies.py	INAPPLICABLE (baseline target, excluded). checks bundled msodbcsql/unixODBC shared libraries and the C++ extension's per-platform file naming; the Rust port ships no ODBC driver and is installed by maturin as one module
test_026_odbc_provider.py	INAPPLICABLE (baseline target, excluded). selects between msodbcsql18 and Microsoft's Rust mssql-odbc ODBC driver at load time; the port speaks TDS directly and loads no ODBC driver (ProviderManager stays importable, see python/mssql_python/odbc_provider.py RUST-PORT)
test_fetch_settings_cache.py::test_native_mixed_fetch_diagnostics	INAPPLICABLE (baseline target, excluded). loads the compiled extension with ctypes and overwrites its exported ODBC function pointers SQLGetDiagRec_ptr / SQLGetDiagField_ptr to inject fake diagnostics; the Rust core has no ODBC layer and no such symbols. The behaviour it guards (fetch diagnostics surface in cursor.messages) is covered by test_messages_errors.py and test_rs_message_flood.py
test_009_pooling.py::test_pool_checkout_validation_timeout	GAP (not a baseline target: pooling socket-proxy tests also fail on upstream in this environment; 15 params). A TCP proxy stalls every TDS response of the idle pooled sockets and the test expects checkout to probe exactly one socket and fall back to a fresh login within the validation timeout (GH #854). The port does not validate a pooled connection at checkout: the session reset piggybacks on the next request (src/connection.rs), so a stalled idle socket is only noticed on the first query ('Checkout probed 0 unresponsive sockets'). Real resilience gap; a fix is a cheap liveness probe with a timeout on pool checkout
test_009_pooling.py::test_pool_checkout_restores_connection_timeout[7]	GAP (not a baseline target; the [0] param passes). A timeout set with conn.set_attr(SQL_ATTR_CONNECTION_TIMEOUT, 7) is not carried over by pool reuse: _get_connection_timeout() on the reused connection differs from the 7 set before close(). Small real gap in pooled attribute restore
test_009_pooling.py::test_pool_checkout_attribute_failure_recovery	INAPPLICABLE (not a baseline target; 8 params). Injects failures by overwriting the extension's exported ODBC function pointers (SQLGetConnectAttr_ptr, SQLSetConnectAttr_ptr, SQLDisconnect_ptr) via ctypes.in_dll; the Rust core has no ODBC layer and exports none of these symbols (ValueError at in_dll)
test_038_mssql_odbc_daily_validation.py	INAPPLICABLE (not a baseline target; 9 tests). Tests upstream's Azure DevOps pipeline files and runner script for the mssql-odbc provider (eng/pipelines/mssql-odbc-daily-validation-pipeline.yml, eng/scripts/run-mssql-odbc-tests.sh, eng/versions/*.version); none exist in this repo and the port loads no ODBC driver
test_release_build_dependencies.py	INAPPLICABLE (not a baseline target; 3 tests). Tests upstream's release engineering files (.github/workflows/refresh-build-dependencies.yml, eng/requirements-build-*.txt, OneBranchPipelines stages) that are not part of this repo
test_fork_coverage_security.py	INAPPLICABLE (not a baseline target; collection error). Needs upstream's .github/scripts/prepare_fork_coverage_comment.py, a CI helper of the upstream repository (FileNotFoundError); the port has its own CI in .github/workflows/
